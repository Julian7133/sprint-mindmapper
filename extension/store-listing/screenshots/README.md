# Chrome Web Store screenshots

## Current image

- `editor-1280x800.png` — actual editor UI with the neutral **Team Plan** sample map.

Captured from the current unpacked Chrome Extension at 1280×800 using a neutral sample map stored temporarily in the browser's local origin storage. The live extension page shows the `AuraMindmap` heading (`extension/editor/index.html:19`); the map contains no personal or customer information. This replaces the illustrative HTML mockup as the store image; the mockup remains only as a design reference.

Chrome Web Store requires **at least one and allows up to five screenshots**. Use **JPEG or 24-bit PNG without an alpha channel**. Accepted screenshot sizes are **1280×800** or **640×400**; use square corners and no added padding. A small promotional tile is **440×280** and optional. See Google's [Supplying Images](https://developer.chrome.com/docs/webstore/images) and [Creating a great listing page](https://developer.chrome.com/docs/webstore/best-listing).
