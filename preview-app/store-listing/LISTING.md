# Google Workspace Marketplace listing — AuraMindmap Viewer

## Title

AuraMindmap Viewer — Markdown Mind Map Preview

## Short description (≤200 characters)

Open markdown mind maps from Google Drive in an interactive preview. Pan, zoom, export HTML/SVG, then edit in the AuraMindmap Chrome extension.

## Detailed description

AuraMindmap Viewer lets Google Workspace users open `.md` sprint mind maps directly from Google Drive. The app renders a full-screen, interactive markmap preview — no install required for viewing.

**What you can do in the viewer**
- Open `.md` files from Drive via **Open with → AuraMindmap Viewer**
- Pan and zoom the mind map; expand and collapse branches
- Download a self-contained HTML export or SVG
- Click **Edit in AuraMindmap** to continue in the Chrome extension (when installed)

**Who it's for**
Teams that store sprint mind maps as markdown in Google Drive and want a fast read-only preview inside Workspace, with an optional path to the full AuraMindmap editor.

**Companion product**
Editing, local folder sync, markers, and offline use are available in the **AuraMindmap** Chrome extension on the Chrome Web Store.

## Single-purpose statement

AuraMindmap Viewer provides a read-only interactive preview of markdown mind map files stored in Google Drive. It is not a launcher-only app — users get pan/zoom navigation and export before any optional edit handoff.
